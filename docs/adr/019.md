# ADR-019: Middleware precedes all effects

**Status:** Accepted

## What must remain true
Authentication, authorization, validation, policy, timeout, correlation, and errors must be consistently applied.

## Chosen boundary
Compose middleware and routes in the Rust service; governance rejects before Application::submit. Always return correlation and a stable error envelope.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-service/src/lib.rs](../../crates/cpm-service/src/lib.rs) |
| caller or test | [crates/cpm-application/src/lib.rs](../../crates/cpm-application/src/lib.rs) |

## Trade-off resolved
Per-route controls can be omitted; policy after handler dispatch is too late.

## Acceptance test
Service tests cover auth, role, policy, validation, timeout/error shape, and zero-effect denial.
