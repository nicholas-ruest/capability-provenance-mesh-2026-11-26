# ADR-014: Receipts are canonical operation evidence

**Status:** Accepted

## Decision statement
Record operation, producer, candidate, correlation, result, timestamps, and raw hashes in an immutable receipt; reject incomplete fields.

## Forces
Runtime logs need a stable, hashable representation that can be joined across layers.

## Code and failure coverage
[crates/cpm-receipts/src/lib.rs](../../crates/cpm-receipts/src/lib.rs) owns the behavior. [crates/cpm-upstream-runtime/src/lib.rs](../../crates/cpm-upstream-runtime/src/lib.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
Handwritten summaries and per-layer identifiers cannot reconstruct causality.

## Done when
Inline tests cover canonicalization and integration traces join UI through upstream to storage.
