# DDD-005: Trial execution lifecycle

## Purpose and scope
TrialRun owns budget, state transitions, scenario identity, and terminal observations.

## State constraints
Only queued may start; only running may complete; terminal states are immutable and budget exhaustion is explicit.

## Realization
| Concern | Existing path |
|---|---|
| aggregate behavior | [crates/cpm-trial-state/src/lib.rs](../../crates/cpm-trial-state/src/lib.rs) |
| integration or failure proof | [crates/cpm-resource-budget/src/lib.rs](../../crates/cpm-resource-budget/src/lib.rs) |

## Completion criterion
Illegal transition/overrun tests pass and restart retrieves one terminal record.
