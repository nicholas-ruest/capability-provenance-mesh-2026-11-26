# ADR-010: Budgets are explicit policy

**Status:** Accepted

## Decision statement
Use typed resource budgets with deterministic accounting; budget exhaustion becomes a terminal trial fact.

## Forces
Host defaults cannot safely bound hostile time, output, or operation consumption.

## Code and failure coverage
[crates/cpm-resource-budget/src/lib.rs](../../crates/cpm-resource-budget/src/lib.rs) owns the behavior. [crates/cpm-trial-state/src/lib.rs](../../crates/cpm-trial-state/src/lib.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
Shell timeout alone cannot explain the consumed resource; silent truncation can hide denial evidence.

## Done when
Boundary and overrun tests pass; exhausted trials never activate registry state.
