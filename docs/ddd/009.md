# DDD-009: Accepted registry

## Model and purpose
RegistryEntry references approved candidate, effective grant, attestation, and promotion event.

## Ubiquitous language and invariants
denied/incomplete never become current; rollback advances with a new event. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-registry/src/lib.rs`
- Behavior or failure test: `crates/cpm-registry/tests/pointer_rules.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
restart returns the same current and history. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
