# ADR-015: Human admission state machine

**Status:** Accepted for implementation

## Context and decision
Capability Provenance Mesh must produce a complete source-bound result while preserving human authority and no-effect denial. The decision is: guarded Quarantined, EvidenceReady, Denied, Incomplete, Approved, Promoted, and RolledBack transitions require an actor.

## Rejected alternative
automatic promotion bypasses authority; free-form status permits illegal edges. This alternative fails a product invariant or makes exact-source evidence ambiguous.

## Consequences and ownership
The production owner is `crates/cpm-policy/src/state.rs`. It exposes a typed boundary, preserves raw upstream receipts, and fails closed. The behavior or failure test is `crates/cpm-policy/tests/transitions.rs`. No adapter may call the accepted registry directly; cpm-application remains the transaction boundary.

## Acceptance evidence
API rejects illegal transitions and audit names actor. Evidence comes from real execution outside the checkout and binds the exact clean source SHA. A change requires a superseding ADR and reciprocal updates to crate, test, DDD record, and composition report.
