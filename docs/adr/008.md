# ADR-008: Risk preserves critical findings and dissent

**Status:** Accepted

## Security invariant
Averages can erase one critical finding among mild evidence.

## Rule adopted
Compute deterministic, order-independent risk where critical observations remain explicit blockers and every contribution stays explainable.

## Implementation surface
- Domain or production source: [crates/cpm-risk/src/lib.rs](../../crates/cpm-risk/src/lib.rs)
- Co-located test or reciprocal caller: [crates/cpm-admission/src/lib.rs](../../crates/cpm-admission/src/lib.rs)

## Why the simpler route fails
Opaque probabilities and arithmetic means are irreproducible and vulnerable to dilution.

## Observable acceptance
Permutation tests agree and the API renders server reasons without recomputation.
