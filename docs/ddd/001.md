# DDD-001: Bounded-context map

## Model and purpose
Intake owns identity; Evidence observations; Trial bounded execution; Governance decisions; Remediation proposals; Registry promoted pointers; Audit causality.

## Ubiquitous language and invariants
CandidateDigest and CorrelationId cross contexts; raw upstream types do not. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-application/src/lib.rs`
- Behavior or failure test: `crates/cpm-application/tests/context_boundaries.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
composition shows no adapter-to-registry shortcut. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
