# ADR-011: Trials use guarded persisted transitions

**Status:** Accepted

## What must remain true
Retries and restart can otherwise duplicate execution or leave a permanent running state.

## Chosen boundary
Allow queued to running to one terminal state; reject duplicate completion and terminal escape. Persist terminal records for replay.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-trial-state/src/lib.rs](../../crates/cpm-trial-state/src/lib.rs) |
| caller or test | [scripts/browser-journeys.spec.cjs](../../scripts/browser-journeys.spec.cjs) |

## Trade-off resolved
Memory locks vanish on restart and status strings permit illegal transitions.

## Acceptance test
Inline transition failures and backend-restart retrieval prove one terminal outcome.
