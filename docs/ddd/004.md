# DDD-004: Quarantined trial execution

## Model and purpose
TrialRun is leased by candidate/scenario in an Agenticow child branch and yields immutable observations.

## Ubiquitous language and invariants
Queued, Running, and one terminal state; parent/dispatch snapshots are invariants. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-trial/src/lib.rs`
- Behavior or failure test: `crates/cpm-agenticow/tests/no_escape.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
journey supplies before and after hashes. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
