# ADR-025: Exact-source evidence gates publication

**Status:** Accepted

## Trigger
A green smoke test or recorder acknowledgement is not a complete product and must never create a remote shell.

## Outcome
Collect ten suite receipts, schema-2 manifest/composition, semantic review, Rust-share inventory, and exact-head CI against one clean SHA. Publication controller must parent the first personal-owner publisher.

The controlling implementation is [scripts/collect-product-evidence.sh](../../scripts/collect-product-evidence.sh); its reciprocal production/test boundary is [scripts/dream-machine-publication-gate.mjs](../../scripts/dream-machine-publication-gate.mjs).

## Option declined
Direct git/gh/API publication and evidence rebinding break the ordering guarantee.

## Evidence contract
Negative control performs zero writes; complete check passes before any non-draft PR child process.
