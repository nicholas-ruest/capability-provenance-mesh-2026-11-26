# ADR-017: Subprocess execution is one hardened runtime

**Status:** Accepted

## Trigger
All integrations need the same timeout, argv, output hashing, and failure capture.

## Outcome
Centralize process mechanics in cpm-upstream-runtime while leaving project semantics in typed modules. Runtime errors retain command evidence.

The controlling implementation is [crates/cpm-upstream-runtime/src/lib.rs](../../crates/cpm-upstream-runtime/src/lib.rs); its reciprocal production/test boundary is [crates/cpm-upstreams/src/common.rs](../../crates/cpm-upstreams/src/common.rs).

## Option declined
Seven copies of process launching would drift; project-neutral runtime cannot interpret domain output.

## Evidence contract
Runtime tests cover configured/unconfigured/failure paths and every adapter returns evidence hashes.
