# DDD-007: Remediation and recovery

## Model and purpose
Proposal references denied digest, Autogenous patch receipt, watermarked explanation, and new digest.

## Ubiquitous language and invariants
proposal has no authority; new digest re-enters evidence; rollback is a new event. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-remediation/src/lib.rs`
- Behavior or failure test: `crates/cpm-remediation/tests/reentry.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
recovery proves reversible promotion. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
