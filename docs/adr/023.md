# ADR-023: Frontier evaluation compares decisions, not just time

**Status:** Accepted

## What must remain true
The rejected benchmark timed one test and called integration failures ablations.

## Chosen boundary
Compare baseline versus full provenance mechanism on unsafe admission, safe acceptance, and runtime. Disable graph, attenuation, lineage, and upstream consensus one at a time.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-application/src/bin/benchmark.rs](../../crates/cpm-application/src/bin/benchmark.rs) |
| caller or test | [crates/cpm-application/src/bin/ablation.rs](../../crates/cpm-application/src/bin/ablation.rs) |

## Trade-off resolved
Integration failure scripts test wiring, not mechanism contribution.

## Acceptance test
Run scripts emit corpus-bound JSON and each mechanism-off result reports a decision delta.
