# DDD-003: Capability semantics

## Model and purpose
Declared, observed, requested, and allowed sets remain distinct; EffectiveGrant is their monotonic intersection.

## Ubiquitous language and invariants
unknown triples never enter EffectiveGrant; diffs explain attenuation. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-capabilities/src/lib.rs`
- Behavior or failure test: `crates/cpm-capabilities/tests/properties.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
denial and ablation prove no widening. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
