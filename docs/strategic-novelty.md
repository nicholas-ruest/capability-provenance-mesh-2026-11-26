## Frontier mechanism: evidence-closed capability admission

The frontier mechanism is **Evidence-Closed Capability Admission (ECCA)**. It is a normative, falsifiable design; exact-head tests and source-bound receipts, not this description, determine conformance.

Inputs are normalized candidate bytes B, typed manifest M, policy P, isolated quarantine state Q, and the required upstream responsibility set U. For this product, |U| = 7. The output is Accepted, Denied, or Incomplete plus a correlation-bound evidence record.

    digest = SHA256(normalize(B))
    require digest == M.artifact_sha256
    q = quarantine_copy(B, parent_isolation = true)
    for responsibility u in U:
        receipt[u] = execute_pinned_upstream(u, candidate_derived_input(q, M))
        require receipt[u].candidate_digest == digest
        require receipt[u].revision == pinned_revision(u)
        add_typed_receipt_edges(graph, receipt[u])
    require graph_reaches_candidate(graph, every(U))
    require authority_never_increases(graph, M.requested_authority)
    require every_declared_effect_is_reversible_or_denied(graph)
    require security_inspection_is_clean(receipt[SkillSpector])
    require signature_subject_and_digest_match(receipt[Cosign], digest)
    decision = evaluate(P, graph, q)
    if decision != Accepted:
        append_decision_audit(decision)
        return decision without registry promotion
    atomically append admission audit and promote q to registry
    return Accepted with replayable correlation

Let b be candidate bytes, r be required responsibilities, v graph vertices, e graph edges, and C(u) an upstream execution cost. Local work is O(b + v + e + r); total latency is O(b + v + e + sum C(u)), and stored evidence is O(v + e + r). In practice, pinned upstream execution dominates local graph traversal.

### Invariants and failure behavior

1. **Candidate binding:** every counted receipt carries the submitted digest, candidate-derived input and immutable upstream revision.
2. **Responsibility closure:** every required responsibility is reachable from the candidate node; a merely successful unrelated probe cannot close the graph.
3. **Authority attenuation:** derived authority is a subset of requested and policy-permitted authority.
4. **Effect isolation:** denial, validation failure, upstream failure and timeout cannot advance the active registry pointer or dispatch the candidate.
5. **Atomic audit/promotion:** an Accepted registry pointer and its admission audit become visible together; replay verifies correlation and hashes.

Digest mismatch, missing receipt, wrong revision, inspector rejection, signature subject/digest mismatch, excessive authority, non-reversible effects, upstream timeout/unavailability, or durable append failure all fail closed as Denied or Incomplete. Recovery requires a corrected candidate and full reevaluation; receipts are not rebound across candidates.
