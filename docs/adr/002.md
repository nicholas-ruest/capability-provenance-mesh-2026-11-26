# ADR-002: Candidate identity begins with normalized bytes

**Status:** Accepted

## Decision statement
Normalize submitted bytes, reject empty input, and derive the candidate digest before parsing or upstream execution. Retries over identical bytes are idempotent.

## Forces
Client labels and repository names are mutable and cannot identify inspected content.

## Code and failure coverage
[crates/cpm-artifact-intake/src/lib.rs](../../crates/cpm-artifact-intake/src/lib.rs) owns the behavior. [crates/cpm-application/src/lib.rs](../../crates/cpm-application/src/lib.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
Client supplied IDs and revision-only identity allow different archives to collide.

## Done when
The digest must recur in decision, upstream evidence, audit, registry, and UI.
