# ADR-016: Directory storage uses atomic append semantics

**Status:** Accepted

## Security invariant
Durable retrieval must survive process restart without a private service database.

## Rule adopted
Write content-addressed decision/audit records and atomically update active projections. Reopen the directory on service start.

## Implementation surface
- Domain or production source: [crates/cpm-store/src/lib.rs](../../crates/cpm-store/src/lib.rs)
- Co-located test or reciprocal caller: [crates/cpm-service/src/lib.rs](../../crates/cpm-service/src/lib.rs)

## Why the simpler route fails
Overwriting a single JSON document loses causal history; service-owned database violates shared storage.

## Observable acceptance
Store tests cover persistence/corruption and browser restart returns the same decision.
