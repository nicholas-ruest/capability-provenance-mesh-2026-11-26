# ADR-015: Registry activation is not decision creation

**Status:** Accepted

## What must remain true
A positive decision must not silently become the current installed capability.

## Chosen boundary
Store decisions and active entries separately. Activate only accepted candidates; rollback writes a new event selecting a prior digest.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-registry/src/lib.rs](../../crates/cpm-registry/src/lib.rs) |
| caller or test | [frontend/src/ProductApp.test.tsx](../../frontend/src/ProductApp.test.tsx) |

## Trade-off resolved
One mutable record loses history and lets denial bugs alter current state.

## Acceptance test
Denied cases remain queryable but absent from active records; rollback preserves both histories.
