# DDD-009: Active registry

## Model
ActiveRecord refers only to an accepted DecisionRecord and its candidate digest. Denied/incomplete decisions remain history, never current.

## Invariants
Activation and rollback are explicit application commands. Current state is a projection over append-only records.

## Ownership map
- Primary implementation: [crates/cpm-registry/src/lib.rs](../../crates/cpm-registry/src/lib.rs)
- Collaborator or test boundary: [crates/cpm-application/src/lib.rs](../../crates/cpm-application/src/lib.rs)

## Acceptance
Registry tests reject denied activation; browser audit preserves both attempts.
