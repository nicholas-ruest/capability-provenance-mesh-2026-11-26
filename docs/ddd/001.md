# DDD-001: Context map and dependency direction

## Ubiquitous language
Intake, Evidence, Trial, Governance, Remediation, Registry, and Delivery are bounded contexts. CandidateDigest and CorrelationId cross boundaries; upstream structs do not.

## Aggregate rule
Service depends on Application; Application depends on domain ports; adapters and DirectoryStore implement ports. No adapter imports registry policy.

The implemented owner is [crates/cpm-application/src/lib.rs](../../crates/cpm-application/src/lib.rs). The reciprocal caller/test is [crates/cpm-service/src/lib.rs](../../crates/cpm-service/src/lib.rs).

## Evidence of the boundary
Composition report proves each member has a caller and no adapter-to-registry shortcut.
