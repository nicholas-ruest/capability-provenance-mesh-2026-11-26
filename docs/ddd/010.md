# DDD-010: Upstream anti-corruption

## Model and purpose
seven typed adapters own pin, license, argv, parsing, and failure normalization.

## Ubiquitous language and invariants
adapters cannot call policy/registry; raw receipts remain inspectable. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-skillspector/src/lib.rs`
- Behavior or failure test: `tests/integrations/all-upstreams.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
all seven have intended and failure execution. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
