# ADR-022: Application owns transaction boundaries

**Status:** Accepted

## Decision statement
Application::submit coordinates intake through upstream evidence and admission, then appends decision/audit and activates only accepted records.

## Forces
Twenty crates need one use-case owner that sequences writes and prevents denied side effects.

## Code and failure coverage
[crates/cpm-application/src/lib.rs](../../crates/cpm-application/src/lib.rs) owns the behavior. [crates/cpm-registry/src/lib.rs](../../crates/cpm-registry/src/lib.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
Letting adapters write storage bypasses governance; service-owned sequencing couples HTTP to domain.

## Done when
Application tests prove all upstreams run, denial is not active, and persistence occurs in order.
