# ADR-025: Governed publication order

**Status:** Accepted for implementation

## Context and decision
Capability Provenance Mesh must produce a complete source-bound result while preserving human authority and no-effect denial. The decision is: pinned controller is parent of the first personal-owner repository/push/PR publisher after complete proof.

## Rejected alternative
direct git, gh, or API bypasses order; evidence rebinding severs truth. This alternative fails a product invariant or makes exact-source evidence ambiguous.

## Consequences and ownership
The production owner is `scripts/dream-machine-publication-gate.mjs`. It exposes a typed boundary, preserves raw upstream receipts, and fails closed. The behavior or failure test is `scripts/tests/publication-negative-control.sh`. No adapter may call the accepted registry directly; cpm-application remains the transaction boundary.

## Acceptance evidence
receipt proves non-draft PR, exact-head CI, and zero negative-control writes. Evidence comes from real execution outside the checkout and binds the exact clean source SHA. A change requires a superseding ADR and reciprocal updates to crate, test, DDD record, and composition report.
