# ADR-005: Lineage records immutable ancestry

**Status:** Accepted

## Trigger
A digest says what bytes were inspected but not source, license, parent repair, or rollback ancestry.

## Outcome
Bind repository, immutable revision, license, and parent digest as cycle-free lineage. Repairs always receive a new digest.

The controlling implementation is [crates/cpm-lineage/src/lib.rs](../../crates/cpm-lineage/src/lib.rs); its reciprocal production/test boundary is [crates/cpm-store/src/lib.rs](../../crates/cpm-store/src/lib.rs).

## Option declined
Audit prose is not queryable lineage; mutating a parent hides which bytes had evidence.

## Evidence contract
Cycle tests fail; recovery evidence shows distinct denied and repaired digests.
