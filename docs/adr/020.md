# ADR-020: OpenAPI is the sole public contract source

**Status:** Accepted

## Security invariant
The first drift check compared against a second JSON schema and missed a changed field type.

## Rule adopted
Generate TypeScript schema from api/openapi.yaml and structurally compare generated output. Negative tests mutate required/type data and require failure.

## Implementation surface
- Domain or production source: [api/openapi.yaml](../../api/openapi.yaml)
- Co-located test or reciprocal caller: [tests/api/contract-drift.test.sh](../../tests/api/contract-drift.test.sh)

## Why the simpler route fails
Substring checks and dual hand-maintained schemas produced a demonstrated false negative.

## Observable acceptance
Generation must be clean and negative mutation tests must make the official checker exit nonzero.
