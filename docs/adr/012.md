# ADR-012: Admission has Accepted, Denied, and Incomplete

**Status:** Accepted

## Security invariant
Tool failure is different from policy violation, and evidence success is different from promotion.

## Rule adopted
Evaluate artifact, lineage, authority, graph, risk, trial, and evidence as a conjunction. Return one of three typed outcomes; activation is a later transaction.

## Implementation surface
- Domain or production source: [crates/cpm-admission/src/lib.rs](../../crates/cpm-admission/src/lib.rs)
- Co-located test or reciprocal caller: [api/openapi.yaml](../../api/openapi.yaml)

## Why the simpler route fails
A score threshold ignores nonnumeric invariants; treating scan success as admission bypasses governance.

## Observable acceptance
Table tests cover all outcomes and denial produces no active registry record.
