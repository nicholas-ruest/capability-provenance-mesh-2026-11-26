# ADR-006: Normalize observations before policy

**Status:** Accepted

## Decision statement
Translate every execution into producer, subject digest, kind, severity, summary, and raw-evidence hash. Failure is incomplete evidence, never an empty clean result.

## Forces
Tool-specific output and exit semantics would otherwise leak into governance.

## Code and failure coverage
[crates/cpm-observation/src/lib.rs](../../crates/cpm-observation/src/lib.rs) owns the behavior. [crates/cpm-upstreams/src/common.rs](../../crates/cpm-upstreams/src/common.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
Directly passing tool JSON makes policy depend on seven external schemas.

## Done when
Validation rejects missing identity/hash and integration traces link raw output to typed observations.
