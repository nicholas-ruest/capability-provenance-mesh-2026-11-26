# ADR-020: Versioned OpenAPI client

**Status:** Accepted for implementation

## Context and decision
Capability Provenance Mesh must produce a complete source-bound result while preserving human authority and no-effect denial. The decision is: api/v1 OpenAPI generates the only TypeScript client and tracked output regenerates cleanly.

## Rejected alternative
handwritten fetch drifts; internal Rust models are not public API. This alternative fails a product invariant or makes exact-source evidence ambiguous.

## Consequences and ownership
The production owner is `crates/cpm-service/src/api/v1.rs`. It exposes a typed boundary, preserves raw upstream receipts, and fails closed. The behavior or failure test is `tests/api/openapi-drift.test.ts`. No adapter may call the accepted registry directly; cpm-application remains the transaction boundary.

## Acceptance evidence
browser uses the checked generated client. Evidence comes from real execution outside the checkout and binds the exact clean source SHA. A change requires a superseding ADR and reciprocal updates to crate, test, DDD record, and composition report.
