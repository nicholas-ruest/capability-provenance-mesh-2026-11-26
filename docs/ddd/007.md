# DDD-007: Remediation proposal

## Ubiquitous language
Proposal is a child of a denied digest with change set, generated explanation provenance, and new candidate bytes.

## Aggregate rule
Proposal has no authority. It re-enters intake, evidence, and admission. Rollback selects an old accepted digest through a new event.

The implemented owner is [crates/cpm-remediation/src/lib.rs](../../crates/cpm-remediation/src/lib.rs). The reciprocal caller/test is [crates/cpm-upstreams/src/autogenous.rs](../../crates/cpm-upstreams/src/autogenous.rs).

## Evidence of the boundary
Recovery journey records parent/new digests and a second evaluation.
