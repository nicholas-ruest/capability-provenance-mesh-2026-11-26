# DDD-012: Operator delivery boundary

## Model
The versioned HTTP API and typed React client expose decisions, active registry, audit, health, and correlation without exposing internal crate structs.

## Invariants
OpenAPI is authoritative; middleware enforces actor and policy before orchestration. UI renders server outcomes and accessible lifecycle states.

## Ownership map
- Primary implementation: [api/openapi.yaml](../../api/openapi.yaml)
- Collaborator or test boundary: [frontend/src/ProductApp.tsx](../../frontend/src/ProductApp.tsx)

## Acceptance
Contract-negative tests, frontend tests, and three Playwright journeys verify the boundary.
