# ADR-021: The browser renders server-owned lifecycle state

**Status:** Accepted

## Trigger
Operators need evidence, denial/recovery, registry, and audit views without duplicating governance.

## Outcome
ProductApp uses the typed client and renders checking, loading, success, denied, empty, and error states with ARIA status/alert semantics.

The controlling implementation is [frontend/src/ProductApp.tsx](../../frontend/src/ProductApp.tsx); its reciprocal production/test boundary is [frontend/src/ProductApp.test.tsx](../../frontend/src/ProductApp.test.tsx).

## Option declined
A generic form hides the system; client-side policy can diverge from Rust.

## Evidence contract
Unit and three real Playwright journeys cover primary, denial/recovery, refresh/restart, desktop/mobile.
