# DDD-005: Evidence graph

## Model and purpose
Candidate, Source, Finding, Trial, Envelope, Receipt, and Decision nodes are joined by required edges.

## Ubiquitous language and invariants
RuGraph supplies mechanics while cpm-graph owns meaning and completeness. Commands carry explicit identity and expected prior state. Queries return source-bound projections. Adapter failure cannot masquerade as domain approval.

## Ownership and verification
- Production path: `crates/cpm-graph/src/lib.rs`
- Behavior or failure test: `crates/cpm-graph/tests/completeness.rs`
- Orchestration boundary: `crates/cpm-application/src/lib.rs`
- API boundary: `crates/cpm-service/src/api/v1.rs`

## Acceptance evidence
missing edge blocks governance. Composition schema 2 maps this record reciprocally to production callers and tests; external evidence is exact-SHA bound.
