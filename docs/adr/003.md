# ADR-003: Parse declarations once into a domain manifest

**Status:** Accepted

## What must remain true
Seven tools cannot each infer capability declarations from prose without semantic drift.

## Chosen boundary
Parse one typed manifest, reject malformed and duplicate declarations, and pass that value to capability evaluation.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-manifest/src/lib.rs](../../crates/cpm-manifest/src/lib.rs) |
| caller or test | [api/openapi.yaml](../../api/openapi.yaml) |

## Trade-off resolved
A permissive map hides aliases; parser-owned authorization mixes description with permission.

## Acceptance test
Inline valid/invalid parser tests and a browser submission must exercise the same grammar.
