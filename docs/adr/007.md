# ADR-007: Completeness is a connected effect graph

**Status:** Accepted

## What must remain true
A pile of valid receipts can omit the causal relationship needed for admission.

## Chosen boundary
Model candidate, declaration, observation, trial, decision, and receipt edges; require a digest-connected path before admission. RuGraph supplies mechanics, not policy.

## Concrete mapping
| Role | Existing path |
|---|---|
| owner | [crates/cpm-effect-graph/src/lib.rs](../../crates/cpm-effect-graph/src/lib.rs) |
| caller or test | [crates/cpm-upstreams/src/rugraph.rs](../../crates/cpm-upstreams/src/rugraph.rs) |

## Trade-off resolved
Flat lists cannot distinguish missing edges; external reachability cannot grant authority.

## Acceptance test
Graph-off ablation must increase unsafe admission on the frozen corpus.
