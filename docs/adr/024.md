# ADR-024: Containers follow the verified rootless topology

**Status:** Accepted

## Security invariant
The host cannot rely on privileged containers or default slirp access to a tunnel device.

## Rule adopted
Build API and web images, share durable data, and use the compatible host-network topology. Cloud Run files remain configuration only.

## Implementation surface
- Domain or production source: [compose.yml](../../compose.yml)
- Co-located test or reciprocal caller: [scripts/container-readiness.sh](../../scripts/container-readiness.sh)

## Why the simpler route fails
Privileged mode changes host policy; a one-container smoke cannot prove the product topology.

## Observable acceptance
Container verification builds, launches, reaches readiness, saves/retrieves a result, and stops.
