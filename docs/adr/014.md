# ADR-014: Leased bounded trials

**Status:** Accepted for implementation

## Context and decision
Capability Provenance Mesh must produce a complete source-bound result while preserving human authority and no-effect denial. The decision is: state persists before execution, is leased by candidate/scenario, resource-bounded, and atomically terminal.

## Rejected alternative
memory locks vanish; unlimited output permits exhaustion. This alternative fails a product invariant or makes exact-source evidence ambiguous.

## Consequences and ownership
The production owner is `crates/cpm-trial/src/lease.rs`. It exposes a typed boundary, preserves raw upstream receipts, and fails closed. The behavior or failure test is `crates/cpm-trial/tests/output_limit.rs`. No adapter may call the accepted registry directly; cpm-application remains the transaction boundary.

## Acceptance evidence
restart shows one invocation and the same receipt. Evidence comes from real execution outside the checkout and binds the exact clean source SHA. A change requires a superseding ADR and reciprocal updates to crate, test, DDD record, and composition report.
