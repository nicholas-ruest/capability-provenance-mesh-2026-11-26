# ADR-018: Seven integrations share one crate but not one type

**Status:** Accepted

## Decision statement
Use cpm-upstreams with separate modules and request/result types for Autogenous, RuGraph, Agenticow, Watermark, LatentMesh, SkillSpector, and Cosign. UpstreamSet executes the production composition.

## Forces
The review proved package-per-project wrappers were duplicate ceremony, yet each project still performs a distinct responsibility.

## Code and failure coverage
[crates/cpm-upstreams/src/lib.rs](../../crates/cpm-upstreams/src/lib.rs) owns the behavior. [crates/cpm-upstreams/src/skillspector.rs](../../crates/cpm-upstreams/src/skillspector.rs) supplies the co-located tests, public contract, or real caller used to prove it.

## Rejected design
A generic string adapter would erase project contracts; separate crates repeated only delegation.

## Done when
Module tests assert distinct validation/failure semantics and the suite calls every module.
