# ADR-009: Scenarios are versioned domain fixtures

**Status:** Accepted

## Trigger
A frontier claim needs identical inputs across baseline, full mechanism, and ablations.

## Outcome
Represent safe, malicious, ambiguous, tampered, and exhausted cases in one typed corpus with deterministic identity.

The controlling implementation is [crates/cpm-scenarios/src/lib.rs](../../crates/cpm-scenarios/src/lib.rs); its reciprocal production/test boundary is [crates/cpm-application/src/bin/experiment_support/mod.rs](../../crates/cpm-application/src/bin/experiment_support/mod.rs).

## Option declined
Live samples drift; timing one unit test does not measure unsafe admission.

## Evidence contract
Benchmark and ablation outputs name the same corpus and repeat decisions.
