# ADR-013: Agenticow no-effect branches

**Status:** Accepted for implementation

## Context and decision
Capability Provenance Mesh must produce a complete source-bound result while preserving human authority and no-effect denial. The decision is: trials run in child branches with parent/dispatch snapshots and bounded cleanup.

## Rejected alternative
shared mutable checkout weakens proof; mocks miss effects. This alternative fails a product invariant or makes exact-source evidence ambiguous.

## Consequences and ownership
The production owner is `crates/cpm-agenticow/src/lib.rs`. It exposes a typed boundary, preserves raw upstream receipts, and fails closed. The behavior or failure test is `crates/cpm-agenticow/tests/isolation.rs`. No adapter may call the accepted registry directly; cpm-application remains the transaction boundary.

## Acceptance evidence
denial records child changes and unchanged parent. Evidence comes from real execution outside the checkout and binds the exact clean source SHA. A change requires a superseding ADR and reciprocal updates to crate, test, DDD record, and composition report.
