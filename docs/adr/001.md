# ADR-001: Count behavior, not package names

**Status:** Accepted

## Trigger
The first review found seven duplicated wrapper crates that inflated the graph without owning seven behaviors.

## Outcome
Keep exactly 20 production crates. Consolidate project integrations into cpm-upstreams while retaining separate typed modules. A crate counts only when its types are called in production and its source contains success and failure tests.

The controlling implementation is [Cargo.toml](../../Cargo.toml); its reciprocal production/test boundary is [crates/cpm-service/src/lib.rs](../../crates/cpm-service/src/lib.rs).

## Option declined
Keeping ceremonial wrappers was rejected because metadata cannot substitute for responsibility.

## Evidence contract
Locked metadata plus composition report must show all 20 reachable from the service root.
