# DDD-003: Capability grant language

## Model
DeclaredCapability, AllowedScope, Observation, and EffectiveGrant are distinct terms. EffectiveGrant can narrow only.

## Invariants
Admission consumes the evaluated grant; neither remediation nor an upstream finding can add a resource/action/scope triple.

## Ownership map
- Primary implementation: [crates/cpm-capability-model/src/lib.rs](../../crates/cpm-capability-model/src/lib.rs)
- Collaborator or test boundary: [crates/cpm-admission/src/lib.rs](../../crates/cpm-admission/src/lib.rs)

## Acceptance
Property tests and attenuation-off ablation demonstrate the invariant.
