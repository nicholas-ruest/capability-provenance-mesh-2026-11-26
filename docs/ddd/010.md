# DDD-010: Upstream anti-corruption boundary

## Ubiquitous language
Each selected project has its own request/result vocabulary inside one meaningful integration crate.

## Aggregate rule
The common runtime owns process mechanics only. Project modules validate Autogenous plans, RuGraph queries, Agenticow contracts, watermark probes, mesh envelopes, inspections, and signatures.

The implemented owner is [crates/cpm-upstreams/src/lib.rs](../../crates/cpm-upstreams/src/lib.rs). The reciprocal caller/test is [crates/cpm-upstream-runtime/src/lib.rs](../../crates/cpm-upstream-runtime/src/lib.rs).

## Evidence of the boundary
