# DDD-006: Admission case

## Model
AdmissionCase owns the conjunction that returns Accepted, Denied, or Incomplete. It does not own registry activation.

## Invariants
A hard violation denies; missing evidence is incomplete; accepted still requires application activation transaction.

## Ownership map
- Primary implementation: [crates/cpm-admission/src/lib.rs](../../crates/cpm-admission/src/lib.rs)
- Collaborator or test boundary: [crates/cpm-risk/src/lib.rs](../../crates/cpm-risk/src/lib.rs)

## Acceptance
Decision tables cover all outcomes and denied records never appear active.
